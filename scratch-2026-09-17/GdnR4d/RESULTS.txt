Exact recurrence
----------------
Serial kernel:
  alpha_t = exp(g_t)
  pred_t  = S_{t-1}^T k_t
  delta_t = beta_t * (v_t - alpha_t * pred_t)
  S_t     = alpha_t * S_{t-1} + k_t * delta_t
  y_t     = S_t^T q_t

Production failure and fix
--------------------------
The algebraic chunk formula was correct, but the kernel evaluated
  exp(G_i-mid) * exp(mid-G_j)
as two independently unbounded factors. Real model C64 gate spans reached about 404,
so selected heads overflowed to NaN although their product exp(G_i-G_j) is <= 1 on
the causal triangle. The fix forms exp(G_i-G_j) directly for the output score and
uses only exp(G_last-G_j) for state accumulation; both exponents are non-positive.

  segment 0 state  NRMSE 0.00270113567;  nonfinite 0
  segment 1 output NRMSE 0.00049130631;  nonfinite 0

Follow-up precision probes
--------------------------
1. The retained bounded implementation already performs the causal decay
   multiplication in FP32: P is an FP32 WMMA accumulator and
   exp(G_i-G_j)*P is evaluated before the single score F16 cast.
   Retained scan profile: 154.122 and 154.721 us/512 rows (mean 154.422).

2. Split-F16 D (hi+lo) for both output and state-carry WMMA:
   seam output NRMSE 0.000272209 / 0.000371455
   seam state  NRMSE 0.001906699 / 0.002733224
   scan profile 151.162 and 166.041 us/512 rows (mean 158.602)
   c24 KLD 0.079851; md5 33332e647033114ebf08bd261b201f87
   This improved the isolated seam but regressed end-to-end KLD; rejected.

3. Split-F16 D for output only, retaining the original carry rounding:
   seam output NRMSE 0.000284496 / 0.000447388
   scan profile 152.762 and 157.962 us/512 rows (mean 155.362)
   c24 KLD 0.079086; md5 3cda5547f1e989a010ee038cd249f361
   This was the best precision probe but still missed 0.078514 by 0.000572;
   rejected. Production remains commit 0a62b5df6.
