Future kernel slice contract — no GEMM implementation in this study.

Weight logical row r is output column of X*W^T; token row t is GEMM M/N transposition independent. Half h spans128 contiguous K coefficients. A[r,t,h]=sum_i(qW[r,h,i]*qX[t,h,i]); S[t,h]=sum_i(qX[t,h,i]); qW0..15, qX-8..7.
Exact real-valued affine result is sum_h d[t,h]*(s[r,h]*A[r,t,h]+z[r,h]*S[t,h]). Existing gfx12/gfx11 IU4_FOLD_RN implements a pinned f32 DAG (sc*d rounded; multiply floatA rounded; zp*d rounded; FMA with floatS; add rounded), so reordering folds is NOT bit-exact even when algebraically exact.

C1/C2/C3 constrain weights only WITHIN each256 group. Their unrelated group scales prohibit one whole-K integer accumulator. Existing activation d[t,h] also varies freely per128, prohibiting even integer combination of two halves unless its product with weight multiplier has a shared group base. One f32 fold per256 is therefore a conditional architecture idea, not an obtained consequence of the weight artifact.

C4 W=B[r]*2^ew*q+z, ew0..8. Paired X=D[t]*2^ex*qX, ex0..2. Code term T=sum_h (A<<[ew+ex]); zero term Z=sum_h z[r,h]*2^ex*S[t,h]. Epilogue y=B[r]*D[t]*float(T)+D[t]*Z (+residual if requested). Z is still an independently accumulated f32 correction for everyoutput, not free. U's single shift fold excludes it; V's measured full-affine register loop models its FMA packet.
C4z z=s*k, k in[-15,0]. T=sum_h (A+k*S)<<[ew+ex]; y=B*D*float(T). Compute corrected half C=A+k*S BEFORE shifting/accumulating; separate full-K dot and zero accumulators could overflow when combined despite cancellation. k*S MAD is still a packet; q+k ranges[-15,15] and is NOT generally signed-i4.
C4s fixedk=-8. Recode each weight nibble q to q xor0x8, interpreted signed-i4 as q-8 in[-8,7]. T=sum_h 2^(ew+ex)*sum_i((qW-8)*qX); y=B*D*float(T). No zero-correction term. This is the U-class register-only shape. Header/global loads, X master reduction, tiling, register lifetimes and epilogue still need full data-fed measurement.

State/ownership transitions:
1. Offline quantizer owns immutable parent BF16, imatrix and fixture reference. AWQ f32 scale formation precedes rotation; sidecars are f16-truncated and must not be substituted for the original pre-scale when reproducing W.
2. Per-row rotated W exists before C4 master choice. No half/group may emit before row-master is frozen. C1..C3 need only a group lifetime.

An optional future compact→qt44 lowering validates header selectors/master lengths and writes private scratch; validate the entire tensor before GPU upload, never mutate source mmap.
6. Activation producer receives original rotated f32 X after unchanged AWQ divide/FWHT. A token-wide reduction of independent MSE best_d produces D=max(best_d)/4. The second pass reads the SAME original f32 values and selects ex0..2 by current integer-code SSE; it must not resnap reconstructed activations. Zero token usesD=1,ex=0,q=S=0.

No retained/replay handle may observe partly rewritten masters/blocks, stale geometry, or another token buffer. Flag-off bypasses new branch completely.
