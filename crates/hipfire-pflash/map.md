## Purpose

Historical reproduction home for PFlash — top-of-prefill speculative compression that scores prompt blocks with a small drafter, keeps high-scoring spans + mandatory anchors (sink, recent window, chat boundaries), and hands compressed tokens to the target prefill. Previously `hipfire_arch_qwen35::pflash` (2,031 lines); lean-up B3 evacuated it here so location matches policy. Prefix caching supersedes it for served workloads. See the `//!` docs in [`src/lib.rs`](src/lib.rs) and GLOSSARY.

## Gotchas

- Legacy — default off. Do not wire into the serve path or depend on from `hipfire-engine`/`hipfire-arch-qwen35`.
- Consumer of `hipfire-arch-qwen35`'s hybrid drafter (DeltaNet + FullAttention); the arch crate must not depend back on this crate (cycle).
