> **Status:** `research` (vocabulary owned by [`docs/GLOSSARY.md`](../../docs/GLOSSARY.md)).

## Purpose

Loop geometry and CPU oracle for the 24-physical-layer, 48-visit Inkling-2-Mini MoE. Validation and visit schedule mirror llama.cpp `inkling2-loop.cpp` at merge `29b52d398b294509746ec0a3f28948a3107c0213`; the oracle operators mirror `inkling2.cpp`. No GPU code, carrier, or generation route yet.

## Gotchas

- Arch ids 24 (trunk) and 25 (MTP sidecar) are provisional educated guesses, not shipped identities.
- `LoopConfig::validate` mirrors upstream exactly: fixed loop needs >= 2 passes, varying >= 1, core block-aligned, `n_slot <= 512`.
- Physical weights are shared across visits (`layer_phys`); KV/conv state is per-visit (48 slots). No GPU state is allocated yet.
