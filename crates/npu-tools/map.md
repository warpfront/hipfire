## Purpose

All XDNA2 NPU binaries in one crate: `npu-tools` (`aie-status`, `txn-dump`, `soc-metrics`, `m4`, `tblgen2rs`, `gpu-bw`, `fclk` subcommands), `npu-gemm`, `npu-hello`, `npu-experts`, `npu-ring`, `npu-railgun`, `npu-bw`, `npu-coop`, and the lab-only `coop27` GPU+NPU co-op prototype (`--features lab`). Runtime comes from `railgun` with `features = ["npu"]`; programs from `peacemaker-npu`. See [`docs/npu/README.md`](../../docs/npu/README.md).

## Gotchas

- Every binary needs real XDNA2 silicon (`/dev/accel/accel0`) and most need a gfx1151 iGPU; run them only inside `tools/npu/npu-window.sh` (FCLK pin + lock), never in CI.
- `native/*.co` and `native/coop27/*.co` are PM-native code objects regenerated by the adjacent `build*.sh` scripts; `coop27` embeds the incumbent `kernels/gemm_mq4g256v2_residual_iu4_pm_v2b_gfx1151.hxaco` directly.
- Concurrent GPU+NPU paths refuse to run unless the fabric clock is pinned (`NPU_FCLK_GUARD`, see `railgun::npu::fclk`).
