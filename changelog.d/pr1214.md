### Changes

- **Gemma 4 batched embedding prefill (HIPF-490): `kernel.gemma4_batched_embedding_prefill` `auto` now also enables on gfx1151 (Strix Halo).** The batched embedding lookup for prefill joins the validated arch set that already covers gfx1100 and gfx1201. Fresh-process receipts, E2B and E4B Q8 and 26B-A4B mq4 vs the flag-off route: sampled tokens, top-k, reasoning and all dumps bitwise identical; cold-prefill throughput 1.02–1.05× (aggregate 1.03×). `HIPFIRE_GEMMA4_BATCHED_EMBEDDING_PREFILL=0` still opts out.
- **Gemma 4 E-series PLE branch projections (HIPF-490): `kernel.gemma4_ple_branch_batched_prefill` `auto` now also enables on gfx1151 (Strix Halo).** The exact-arithmetic batched PLE branch route joins the validated arch set that already covers gfx1100 and gfx1201. Fresh-process receipts, E2B and E4B Q8 vs the flag-off route: sampled tokens, top-k, reasoning and all dumps bitwise identical; cold-prefill throughput 1.08–1.21× (aggregate 1.14×). `HIPFIRE_GEMMA4_PLE_BRANCH_BATCHED_PREFILL=0` still opts out.
- **Perf (gfx1151, Strix Halo): symmetric MQ3 (qt49, `mq3v2.symmetric`) W3A4 prefill is now default-on (HIPF-490): pp4096 3.38x vs the F16 route on the same file (CI [3.360, 3.392], 4 fresh loads per arm).** The gfx11 V2B full-tile consumer (`gemm_mq3v25_residual_iu4_v2b`, 256x256 tiles; gfx1100 keeps V2C) now also builds and launches on gfx1151; rows outside full 256 tiles stay on F16. qwen3.8-27b mq3-xts, one binary, `HIPFIRE_MQ3V25_A4=0` vs default: pp256 244 → 736 tok/s (3.01x, CI [2.994, 3.035]), pp4096 238 → 804 tok/s; AR decode (`--spec off`) 1.1–1.3% slower at 128–20000 context (one A4 outlier load at 8192). Teacher KLD, A4 vs F16, 24 chunks, both arms on gfx1151 (paired 95% t CI): WT2 0.1514 → 0.1712, +0.0198 [0.0153, 0.0243]; code24 0.1000 → 0.1029, +0.0029 [0.0003, 0.0054]; both inside the shipped MQ4-xts IU4 default's own penalty (+0.0290 / +0.0270). This is a route change gated on KLD, not byte-identical to F16. `HIPFIRE_MQ3V25_A4=0` (or `kernel.iu4_prefill=false`) restores F16.
- **Gemma 4 E-series PLE activation fusion (HIPF-490): `kernel.gemma4_ple_activation_fused_prefill` `auto` now also enables on gfx1151 (Strix Halo).** The fused strided GELU·mul PLE activation kernel (`gemma4_ple_gelu_mul_strided_f32`) joins the same validated arch set. Fresh-process receipts, E2B and E4B Q8 vs the flag-off route: sampled tokens, top-k, reasoning and all dumps bitwise identical; cold-prefill throughput 1.04–1.09× (aggregate 1.06×). `HIPFIRE_GEMMA4_PLE_ACTIVATION_FUSED_PREFILL=0` still opts out.
