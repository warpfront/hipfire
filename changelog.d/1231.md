### Fixes: Inkling-2-Mini under memory pressure

- **Fixed (#1231, Inkling-2-Mini, arch 24): the daemon no longer panics with
  `inkling2 gpu fwd: view extent` when the GPU pool is under memory pressure.**
  After an out-of-memory retry the pool can hand a larger buffer to an
  exact-size request (15704 B for a 12288 B view), and `view2` asserted the
  exact size. Every pool-served view cut in `hipfire-arch-inkling2`'s GPU
  forward (`view2`, `head_view`, `copy_row_from`, `dup`, the cross split) now
  goes through a checked prefix view: a larger buffer yields the same logical
  prefix, and a short buffer or an overflowing extent fails the request with
  an error (served as a 503) instead of killing the process. Buffers of the
  exact size take the same path as before. Contributed by raufaser.
