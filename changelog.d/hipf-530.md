### Fixes: kernel packs ship Radiowave certification

- **Fixed: retained-PM4 VMEM acquires were inert on packaged installs.** Kernel packs carried no `.radiowave.json` sidecars, and the runtime certifies only hipcc cache entries that have their `.hip` source, so a pack install certified 0 objects and `HIPFIRE_REPLAY_PM4_GFX11_VMEM_ACQUIRE` (default on for gfx1151) issued 0 acquires (gfx1151 27B mq4-xts, forced PM4: pack 0/22 certified, 0 VMEM launches; JIT 22/22, 514). `KernelCompiler::publish_package` now ships each module's sidecar, pack verification checks every shipped sidecar against its object bytes, and `hipfire-kernel-manifest` refuses a pack where any module lacks one. `build-kernel-pack.sh` passes `RADIOWAVE_BUNDLER/READOBJ/OBJDUMP` through. Older packs without sidecars still install and load uncertified (HIPF-530).
