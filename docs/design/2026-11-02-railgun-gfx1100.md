## Policy rule for products

The gfx1100 table is tier-D (Redline's evidence class). A product lowering MUST use `RowPolicy::UnreceiptedSystem`
(`WaitIdle + System` for every row) until `CacheTable::attach_receipts` has attached a gfx1100 G4 probe table. `RowPolicy::TierD` on gfx1100 is only meaningful for parity diffs against Redline.

## G4 silicon protocol required for gfx1100 receipts

`crates/railgun/examples/g4_probe.rs` already has a `Family::Gfx11` path (builds with `Gfx10Pm4CommandBuffer`; probe rung
names are identical: `wait_inter_node` = GCR 0x380 same-agent, `wait_system` = ROCr system acquire, so the
`probe_rung` mapping needs no change) [INFERENCE from reading the source; the probe has not been run against gfx1100
by this work]. Needed on one pinned XTX (identity asserted in process: name, PCI bus, KFD unique id), >= 2^20 trials
per rung, split over footprint x layout cells, any stale observation disqualifies the rung:

- `raw_vmem`, `raw_smem` (GPU-written data read through the scalar cache), `war`, `waw`, `war_pre_writer`
  (and `pre_writer_after_barrier` for the MoE router -> silu_mul shape);
- rungs: none, wait, wait_vmem, wait_inter_node, wait_l1, wait_global, wait_system;
- output `cache-table.gfx1100.json`, attached with `attach_receipts(.., min_trials = 2^20)`. A clean `wait` rung on
  `war_pre_writer` receipts the gfx11 pre-writer row; a stale one refuses the attach. (An empty row would probe as `none`,
  which removes the WAR wait itself and is stale by construction; fixed after RaonG4X's note, the September gfx1100 run
  had `wait` clean at 2^20.)

## Objects that need certifying

The Raon gfx1100 decode objects are different objects from the gfx1201 ones (hipcc gfx1100 builds, the gfx11 GEN-FA2
twins, the PeaceMaker gfx1100 kernels). Per PROBE.md the gfx1201 run had 24 of 34 (object, symbol) rows proven, 8
`lift_rejected` (ISA table gaps) and 2 `unknown` (MoE pointer tables, since addressed by the sealed-table certificate).
For gfx1100 the equivalent `railgun-cert coverage` has not been run: the peacemaker gfx1100 table lift gaps are unknown.
