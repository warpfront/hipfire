## Cases

- **1a, keep the exact bind.** ON where certified; off elsewhere by design or by hard gate. No hardware is needed. The action is keep, or wire it if the read is raw.
- **1b, widening candidate.** OFF on an arch we own only because nobody tried it. Needs correctness and perf on that machine. "Accessor change first" or "port first" means `=1` does nothing on that arch until the gate or kernel changes.
- **2, measured worse elsewhere.** Per-arch tuning; move it into a typed table.
- **3, capability proxy.** Only where the arch set equals an existing capability.
- **4, known broken elsewhere.** Bind to the safe arches and link the bug.
- **5, model, shape, topology or config conditional.** Belongs in dispatch policy or the model card.
- **6, memory or host policy.** Typed config key plus `FeatureFlags`.
- **7, multi-value mode.** Typed key with an `auto` default.
- **8, unreachable arch path (gfx942/CDNA, gfx906).** Question for Kaden. "+ 8" marks a gfx942 arm on a row whose main case is another.

Two rows are not tier C, because their env is opt-in only: `DEEPSEEK4_HC_FINALIZE_FUSED` and `GFX1151_E8_BUFFER`. Widening to gfx1101, gfx1102, gfx1103, gfx1150, gfx1152 or gfx1200 is "nobody": no one has those parts.
