# Glossary — hipfire named subsystems

> **Attribution.** Several subsystems below originate outside this project or with
> contributors rather than the maintainer. This glossary does not re-state
> origination claims for any subsystem. The authoritative records are
> [`PRIOR-ART.md`](../PRIOR-ART.md) (dated, commit-hash provenance; note that
> one origination claim for **DFlash** was formally withdrawn there in favour of
> Chen, Liang & Liu, arXiv:2602.06036), [`NOTICE`](../NOTICE) (license-grade
> attribution requirements), [`CREDITS.md`](../CREDITS.md) (contributor
> inventory), and the per-file `SPDX-License-Identifier` / `SPDX-FileCopyrightText`
> headers. Consult those files for who originated what; do not infer origination
> from presence in this table.

All `Where it lives` paths are repository-relative and were checked to exist on
the 0.4.2 beta line. `Status` is `production`, `research` or `legacy`;
`legacy` entries are deprecated since 0.4.0 and scheduled for removal in 0.5.0
(see [`CONFIG.md`](CONFIG.md) and [`env-vars.md`](env-vars.md) for per-knob
lifecycle).

| Name | Definition | Where it lives | Status |
|---|---|---|---|
| **DFlash** | Block-diffusion speculative decoder that drafts an entire block in one forward pass conditioned on projected context features from the target model. A 5-layer Qwen3 decoder with non-causal bidirectional attention within the block; the output is a per-position hidden state mapped through the target's `lm_head`. The *method* is prior art (Chen et al., arXiv:2602.06036, 2026-02-05); what ships here is the RDNA lowering and the `attention_dflash` kernel. Off by default (`dflash_mode=off`); the Qwen3.8-27B tiers that declare a paired draft resolve `auto` from the registry. The legacy contiguous-DFlash knobs `HIPFIRE_DFLASH_WINDOW=0` and `HIPFIRE_DFLASH_CTX_CAP` are deprecated since 0.4.0, removal in 0.5.0 (the draft-declared window supersedes them). | `crates/hipfire-runtime/src/dflash.rs` (core) and `kernels/src/attention_dflash.hip` (tiled online-softmax kernel, co-authored; see `PRIOR-ART.md` §8) | `production` |
| **DSpark** | EAGLE-3-style draft-sidecar speculative path (`<stem>-dspark.<ext>` next to the trunk). Arch-agnostic core (`DsparkBody` trait, `main_proj` ingest, Markov and confidence heads, window orchestration) with per-arch bodies for Qwen3-style dense transformers (`hipfire-arch-llama`) and DeepSeek V4. Selectable with `speculation=dspark`; under `speculation=auto` a present sidecar can win over in-trunk MTP ([`CONFIG.md`](CONFIG.md#speculative-decode)). | `crates/hipfire-runtime/src/dspark_core.rs` (generic core); per-arch bodies `crates/hipfire-arch-llama/src/dspark_body.rs`, `crates/hipfire-arch-deepseek4/src/dspark_speculator.rs` | `production` |
| **Redline** | Bare-`libdrm` / direct-KMD GPU dispatch that bypasses the HIP runtime. Parses `.hsaco` ELFs for kernel descriptors, creates compute queues via `amdgpu_cs_ctx_create` ioctls and submits PM4 packets (`WRITE_DATA`, `DISPATCH_DIRECT`, …) without `hipModuleLoad` in the loop. | `crates/redline/src/lib.rs` (crate `redline`; siblings `crates/redline-dispatch/`, `crates/redline-rocr/`) | `research` |
| **DDTree** | Tree-structured speculative verification built from DFlash per-position top-K marginals. Pure-Rust port of Ringel & Romano Algorithm 1: best-first heap, ancestor-only visibility matrix, `follow_verified_tree` greedy walk to select the longest accepted path, with a tree-attention bias overlay on the batched flash paths (`q8`, `fwht{2,3,4}`, `bf16`, and the deprecated `asym{2,3,4}` names). Chain DFlash unless `ddtree_budget` > 0. | `crates/hipfire-runtime/src/ddtree.rs` (construction + walk); verify stage `crates/hipfire-runtime/src/dflash_generic.rs` / `spec.rs` | `research` |
| **PFlash** | Top-of-prefill compression stage that scores source prompt blocks with a small drafter, keeps high-scoring spans plus mandatory anchors (sink, recent window, chat boundaries) and hands the compressed token stream to the target's existing prefill. Decode (DFlash/DDTree/AR) is unchanged. **Deprecated since 0.4.0, removal in 0.5.0** (prefix caching supersedes it); enabling it (`prefill_compression` other than `off`) prints a warning. | `crates/hipfire-pflash/src/pflash.rs` and `kernels/src/pflash/score_fwht{2,3,4}_kv.hip` | `legacy` |
| **CASK** | Core-aware selective KV compression (arXiv:2604.10900) that sits atop TriAttention. Splits the KV budget `B` into a protected core (top-`α·B` tokens kept intact) and mergeable scratch (next `m·(1−α)·B` tokens folded via soft-max-weighted averaging over GQA-aggregated `z`-scores into `(1−α)·B` slots). **Deprecated since 0.4.0, removal in 0.5.0**; not supported, and enabling it prints a warning (`memory.cask.*`, `hipfire sidecar-gen`). | `crates/hipfire-runtime/src/cask.rs` (CPU soft-max merge v1, Q8-only); GPU merge kernels `crates/rdna-compute/src/kernels.rs` (`cask_*`) | `legacy` |
| **Atlas** | Kernel Atlas — typed measurement schema and JSONL writer for the bench corpus. Bench binaries emit `AtlasRow` per phase (`prefill`, `decode_ar`, `decode_dflash`) via `--emit-atlas`; `scripts/kernel_atlas.py` does ranking/iteration, `docs/methodology/kernel-atlas*.md` defines the three-layer split (collection / analysis / advisor). | `crates/hipfire-atlas/src/lib.rs` (schema, `AtlasRow`, `parse`/`render`/`suggest`/`task`) and `docs/methodology/kernel-atlas.md` | `production` |
| **Reap** | Model-agnostic selective expert pruning and re-quant overlay for MoE models (SP2+). Gathers per-expert importance, produces an `ExpertPlan` that prunes or re-quantizes cold experts and is applied as an overlay at load. | `crates/hipfire-reap/src/lib.rs` (modules `gather`, `plan`, `hook`, `load`, `source`); spec `docs/superpowers/specs/2026-06-11-generic-moe-reap-design.md` | `research` |
| **MagnumQuant** | FWHT-rotated weight quantization family (MQ4/MQ8/MQ3/MQ6/MQ2 + Lloyd variants, G256/G128). Applies a Fast Walsh-Hadamard rotation per group offline, then asymmetric (or Lloyd-Max codebook) quantization; activation rotation is fused into `RMSNorm` at GEMV/GEMM time so cost amortizes against existing work. | `kernels/src/fused_rmsnorm_mq_rotate.hip` (fused rotation kernel) and `crates/rdna-compute/src/gemv.rs` (MagnumQuant GEMV family); format `docs/QUANTIZATION.md` | `production` |
| **Radiowave** | Policy boundary between HIP source and LLVM/AMDGPU. Injects reviewed source-level lowering rules, invokes `hipcc`, inspects the emitted code object and records enough evidence to reproduce the build. Vendored from the upstream `redline` repository (`crates/radiowave/VENDOR.md`). | `crates/radiowave/src/lib.rs` (vendored; upstream `https://github.com/Kaden-Schutt/redline` @ `f4a0994`) | `production` |
| **TriAttention** | KV-cache eviction scorer that predicts attention without recomputing it. Exploits pre-RoPE Q/K concentration (`Mean Resultant Length R≈1`) to model the RoPE logit at distance `Δ` as a trigonometric series `Σ ‖E[q_f]‖·‖k_f‖·cos(ω_f·Δ+φ_f)` and scores each cached key by its predicted contribution. The KV-eviction use (CASK path) is **deprecated since 0.4.0, removal in 0.5.0**; the registry `triattn` sidecar on `qwen3.6:27b` is still fetched by `hipfire pull` but nothing attaches it by default. | `crates/hipfire-runtime/src/triattn.rs` (scoring + `EvictionCtx`); kernels `kernels/src/pflash/score_fwht*.hip` share the scoring substrate | `legacy` |
| **Glimmer** | Dense text architecture crate for Muse Glimmer (arch 14) — 3:1 sliding/NoPE-full attention, gated attention, sandwich RMSNorm with split eps, scale-less QK-norm, SiLU SwiGLU, untied `lm_head` with output multiplier and logit softcap. | `crates/hipfire-arch-muse-glimmer/src/glimmer.rs` (crate `hipfire-arch-muse-glimmer`) | `production` |
| **FireMap** | HIP VMM-backed KV cache. Reserves a stable virtual address range for KV via the HIP VMM API (`hipMem*` / `VmmArena`) and grows physical backing page-aligned, keeping graph/retained base pointers stable while paging in chunks. Selected by `kv_backend` (`vmm`); automatic selection is limited to certified platforms (see [`CONFIG.md`](CONFIG.md)). | `crates/hip-bridge/src/vmm.rs` (`VmmArena`); design `docs/plans/2026-07-28-pr549-vmm-all-kv-adaptive-design.md` | `research` |
| **saddle** | The target substrate proposed in the lean-up programme: the interface between model and silicon that owns target-agnostic composition (weight manifests, KV, sampling, grammar, spec-decode orchestration) so per-arch crates become thin trait implementations. | `docs/governance/2026-08-15-saddle-design-grounding.md` (design grounding + layering diagram) and the `saddle-*` workspace crates | `research` |
| **saddle-core** | Crate implementing the saddle substrate's target-agnostic concerns. Declares the modules `grammar`, `kv`, `caps`, `logprobs`, `sampling` and `spec`, and sits **below** `hipfire-runtime` and all `hipfire-arch-*` crates; may depend only on `rdna-compute`, `hip-bridge`, `serde`, `std` (layering contract in `Cargo.toml` + `lib.rs`). | `crates/saddle-core/src/lib.rs` (and `crates/saddle-core/Cargo.toml`); modules `crates/saddle-core/src/{grammar,kv,caps,logprobs,sampling,spec}.rs` | `research` |
| **MTP** | Multi-token-prediction head used as a self-speculative drafter. A native head ships for Qwen3.8-27B (`qwen3.8-27b.mtp` sidecar, HFQ arch 21, registry-declared), Qwen3.6 35B-A3B / Ornith 1.5 sidecars, DeepSeek V4 and Qwen3.8-Flash-Next (embedded). Controlled by `speculation` and `mtp_mode` (both default `auto`). `auto` arms native MTP only for a producer that declares a measured AR floor (`MTP_MEASURED_AR_FLOOR`; today only Qwen4 / Flash-Next); Qwen3.5-class, DeepSeek V4 and Gemma 4 declare none, so `auto` stays AR there and `on` / `--spec mtp` is the explicit opt-in. | `crates/hipfire-arch-qwen35/src/mtp_head.rs` (Qwen head loader and trunk check); `hipfire_config::mtp_mode_admits` (the shared floor gate); registry `mtp` slot in `registry/models.json`; [`MODELS.md`](MODELS.md#dflash-draft-artifacts-registry) | `production` |
| **FWHT KV (`fwhtN`)** | Compact KV-cache formats that rotate K with a Fast Walsh-Hadamard transform before 2/3/4-bit quantization (`fwht2`/`fwht3`/`fwht4`; V stays Q8). Optional headroom modes beside `q8`; the Qwen `asymN` / `turboN` spellings are now aliases of them. | `crates/hipfire-runtime/src/kv_mode.rs`; [`CONFIG.md`](CONFIG.md#mode-k-and-v) | `production` |
| **Givens asym KV** | The earlier Givens-rotation 2/3/4-bit K format (`legacy-asymN`, and bare `asymN` where a loader still maps it to Givens). **Deprecated since 0.4.0, removal in 0.5.0** together with the `asymN` / `turboN` aliases; spell `fwhtN` or `q8`. A load naming one prints a warning. | `crates/hipfire-runtime/src/kv_mode.rs`; kernels `kernels/src/attention_flash_asym*.hip` | `legacy` |
