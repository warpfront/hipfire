# Qwen3.6 27B Speculative Decode on R9700/gfx1201

Date: 2026-05-28

This is a local lab checkpoint for Qwen3.6 27B speculative decode on the
R9700/gfx1201 box. It compares autoregressive decode, Kevin's dense MTP head,
and the existing DFlash drafter on the same AWQ trunk. The worktree was dirty
during the run, so treat these as operational numbers, not a release baseline.

## Takeaways

1. Kevin's Qwen3.6 27B dense MTP head is coherent on the AWQ 27B trunk and
   gives a broad AR uplift on R9700/gfx1201.
2. The useful MTP path is `--compressed-serial --max-n 5 --mtp-p-min 0.5`.
   The plain non-serial/lossy batched path was only about 22-23 tok/s on LRU.
3. DFlash remains the best path when draft-target alignment is good, especially
   code and reasoning. On LRU, DFlash is about 3.1x AR at max=120 and 2.5x AR
   at max=256.
4. MTP has a real niche for short/factual and some low-DFlash-acceptance rows.
   A production router could reasonably prefer DFlash for code/high-confidence
   contexts and MTP for short factual or predicted-low-DFlash-confidence
   contexts.
