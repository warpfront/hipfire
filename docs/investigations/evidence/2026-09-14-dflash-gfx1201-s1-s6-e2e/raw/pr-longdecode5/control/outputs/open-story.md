# 雨后的第七日

暴雨像是一头被困在玻璃罩里的野兽，整整七天，它用浑浊的爪子抓挠着这座城市的每一扇窗户。当第八个清晨的第一缕阳光刺破云层时，积水终于退去，露出了被冲刷得发亮的柏油路面。

林远站在自家阳台上，手里攥着一张皱巴巴的城市地图。那是他祖父留下的旧物，泛黄的纸页上印着三十年前的街道布局。他原本只是想确认一下，昨晚那场罕见的暴雨是否冲垮了城南那座老旧的立交桥。

然而，当他展开地图，目光扫过熟悉的“梧桐大道”时，瞳孔猛地收缩。

在地图的右下角，原本是一片空白的工业区边缘，此刻赫然多出了一条细长的街道。它像是一根黑色的针，突兀地扎在地图的空白处，标注着两个模糊的小字：**“忘川路”**。

林远揉了揉眼睛，以为是雨水浸湿了纸张产生的幻觉。他抓起手机，打开实时导航地图。屏幕上，那条街道并不存在。但当他走出公寓，沿着湿漉漉的街道向城南走去时，他看到了它。

一条狭窄的柏油路，两旁种着从未见过的深紫色藤蔓植物，空气中弥漫着一种类似旧书页和潮湿泥土混合的味道。路尽头，矗立着一座红砖砌成的老式邮局，屋顶的烟囱里正冒着袅袅白烟，仿佛时间在这里凝固。

林远的心跳加速。他记得祖父生前总爱念叨一句话：“有些信，寄得太早，收得太晚。”那时他以为那只是老人的胡话。但现在，看着那座孤零零的邮局，一种难以言喻的寒意顺着脊椎爬了上来。

他推开了邮局那扇沉重的木门。门轴发出刺耳的呻吟，仿佛惊扰了沉睡多年的尘埃。

邮局内部昏暗而安静，空气中漂浮着细小的尘埃颗粒。柜台后坐着一个老人，穿着深蓝色的制服，胸前的徽章已经氧化发黑。老人抬起头，眼神浑浊却异常平静。

“你是来取信的？”老人的声音沙哑，像是砂纸磨过木板。

“我……我不确定。”林远结巴着回答，“这里怎么会有邮局？地图上根本没有这条路。”

老人没有回答，只是从柜台下抽出一个牛皮纸信封，递给了林远。信封上没有寄信人，只有收件人：**林远**。

林远颤抖着手接过信封。信封很轻，但触感粗糙，像是用了很久的纸。他拆开信封，里面是一张折叠整齐的便签纸，字迹苍老而熟悉——那是祖父的字迹。

*“小远：当你看到这封信时，雨应该停了。不要害怕那条路。它不是通往死亡，而是通往被遗忘的记忆。我在里面等你，虽然我已经不在了。记住，有些东西，只有失去后才看得见。”*

林远感到一阵眩晕。祖父去世已经五年了。这封信，难道是从过去寄来的？

“这是谁寄的？”林远问。

“是你自己。”老人淡淡地说，“或者说，是那个还没出生的你，或者那个已经死去的你。时间在这里不是直线，而是漩涡。”

林远不信。他转身想离开，却发现身后的门已经消失了。墙壁上出现了一面巨大的镜子，镜子里映出的不是他现在的样子，而是一个穿着校服、满脸泪痕的少年。那是十五岁的林远，站在祖父的病床前，手里攥着一张未寄出的信。

“你终于来了。”镜子里的少年开口了，声音与林远一模一样，“我等这一天，等了十五年。”

林远惊恐地后退，撞到了身后的货架。货架上堆满了类似的信封，每一个都写着不同的名字，但收件人全是“未来”。

“这是怎么回事？”林远喘息着问。

“暴雨冲刷掉了时间的边界。”老人终于开口，他的身影开始变得透明，“这条街道，是时间溢出的地方。那些被压抑的、未说出口的话、未完成的遗憾，在极端的天气下，会凝结成实体。这座邮局，就是它们的容器。”

林远看着镜子里的少年，突然明白了祖父信中的意思。十五岁那年，祖父病重，林远因为学业压力和青春期的叛逆，拒绝去探望祖父。他写了一封信，想道歉，但最终没有寄出。祖父在孤独中去世，而林远带着这份愧疚活了十五年。

“那封信……”林远喃喃道。

“它一直在这里。”老人指了指货架上的一个信封，“你寄出的不是信，是愧疚。它在这里等待，直到你准备好面对它。”

林远走向那个信封。当他拿起它时，镜子里的少年消失了，取而代之的是祖父年轻时的影像。祖父微笑着，仿佛在说：“没关系，我原谅你。”

林远的眼泪夺眶而出。他终于明白，这条街道不是通往过去，而是通往内心深处的和解。

他走出邮局，发现外面的世界已经变了。那条“忘川路”正在慢慢消失，紫色的藤蔓枯萎，红砖邮局化作尘埃。阳光更加强烈，空气中弥漫着雨后清新的味道。

林远回到家，发现地图上那条街道已经不见了。但他手里还握着那张祖父的便签。他走到书桌前，拿出纸笔，写下了一封信。

*“祖父：对不起，我来晚了。但我终于明白了，爱不是没有遗憾，而是带着遗憾继续前行。”*

他将信折好，放入信封。没有寄信人，没有收件人。他走到窗前，看着远处那片曾经空白的工业区。那里现在建起了一座新的公园，孩子们在草地上奔跑。

林远深吸一口气，将信投入了楼下的公共邮箱。他知道，这封信永远不会被任何人收到，但它已经完成了它的使命。

雨后的城市，依旧喧嚣。但林远知道，有些街道，只存在于心里。
