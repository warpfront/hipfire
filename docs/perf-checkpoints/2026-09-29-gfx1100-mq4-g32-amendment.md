# MQ4 packed G32 precision restoration

Lifecycle: **historical**. Fixture-bound measured evidence, not default
promotion or universal accuracy/performance admission.

Amends the interpretation of the unchanged
[earlier packed/G128 checkpoint](2026-09-29-gfx1100-mq4-packed-wide-prefill.md).
That candidate changed activation quantization from native32-element scales
to128-element scales. Its +33.96% result must not be presented as an
equivalent-precision layout optimization. Old raw evidence remains unchanged.

## Diagnosis and minimal repair

CPU reconstruction from actual GPU activation bytes reproduced the
inter-route GEMM differences. Both kernels matched their own quantized
contracts (sampled relL2 about1e-7), but those contracts differed. On the
real model, layer00 recurrent state was identical and layer01 diverged;
prefill-logit relL2 reached0.1977 despite identical forced input tokens.

Retain X256/Y64 tiling, quad-row loads and nibble permutation. Restore
amax reduction over32 elements, consume each independent scale with a
per32 integer dot, and apply each zero correction in native order. Changing
only the quantizer would be wrong because the G128 consumer shares one scale.
Legacy quantizer symbol spelling is retained; comments clarify its contract.

## Validation

- Both actual FFN shapes at N512: all packed activation bytes and output
  values exactly equal native MMQ; independent sampled CPU oracle agrees.
- Real model512 rows (both chunk512) and8193 rows (native512/packed4096):
  646 numeric records per case equal, including raw-comparable state and
  four forced continuation steps; no nonfinite values. This is bounded
  fixture evidence, not a proof for every input or architecture.
- Warmed capture: stable prefill1332/20 and decode659/16; four-position
  HIP/PM4/blob/GDN parity passes. Captured paths intentionally fall back;
  unchanged beta cold-capture scratch pre-growth limitation is still known.
- MQ4V2 packed SET/ADD compatibility smoke completes PP8192/TG256. No
  MQ4V2 speedup or native-equivalence claim is made by that smoke.
- Release build, packed-admission unit test1/1, whitespace check pass.
