## CPU checks and limitations

Product daemon/CLI release build, install-revision/uninstall tests, touched
crate maps and whitespace checks passed. Full-tree checks are **not green**:

- Missing scratch includes in `kx3_foldfree_probe`: reproduced on clean beta.
- Loader unsupported-VMM test: reproduced on clean beta.
- Five mq4c_repack Python failures: reproduced on clean beta.
- Structural ratchets, env-docs and broad map drift also fail on clean beta.
- Candidate workspace no-fail-fast additionally reports a kernel-registry
  source-hash test failure. This still requires its own baseline runtime check.
- Redline Python checks fail on both trees, but baseline has additional
  environment-dependent errors; do not describe these runs as identical failures.

New example and bypass counts are being removed in a separate cleanup. This
checkpoint validates the frozen numerical implementation, not an untested later
binary; dispatch cleanup must carry its own targeted verification record.

Historical speed-gate uses a different fixture from this W7900/Q8/VMM run.
No thresholds were raised. Canonical MQ4V2/AWQ quality remains unvalidated;
the existing older-artifact MQ4V2 smoke is not extended into a parity claim.
