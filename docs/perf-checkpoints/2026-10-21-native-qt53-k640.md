## Selected change

The QT53 indexed down carried dynamic K and group/tail control even for the
known 640-wide input. Compile the same arithmetic with constexpr K=640.
The wave32 lane decomposition, per-output addition/reduction order, asymmetric
scale/zero decoding, invalid-expert zero output and flat unweighted layout are
retained. Route weighting remains the combine's responsibility exactly once.
No new allocation, data pass, copy, synchronization or environment knob.

The exact gfx1151 M2560/K640/top-10, 1..8-row path is selected in both the
scalar AR and batched native MTP consumers. Other shapes and architectures
retain the generic route. The original public dynamic-K launcher remains
available. Both entries use the same arithmetic source; it is an independent
compilation/ABI comparison, not a second mathematical implementation.
Four pointers + four i32 retain the 48-byte ABI and ordinary graph/timer funnel.
