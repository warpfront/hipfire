# Kernel-agnostic beta/alpha fold: gate evidence

- Branch: `gfx11-betaalpha-fold`, rebased from `ef52914a4` onto landed Halo V2B `mq4-lloyd` `900e52771`. The gfx1100 A/B traces below used the pre-rebase binaries built from `ef52914a4` and the fold respectively; the Halo gates use the rebased binary and V2B baseline.
- The load path concatenates complete MQ4V2 Z, beta and alpha rows, preserving all 136-byte groups. It pads SET's row count to 128 on gfx1100 or 256 on gfx1151. The same existing production SET selector handles QKV and folded Z; a small HIP split writes the original Z/beta/alpha F32 output layout. No GEMM kernel is forked. Default on only for the exact four-MQ4V2 Qwen3.5 LA route, `HIPFIRE_IU4_BAFOLD=0` disables it. Decode and fallback retain the original beta/alpha weights.
- Source proof: local `cargo check -p hipfire-arch-qwen35 -q`; `hipcc --offload-arch=gfx1100 --offload-arch=gfx1151 -c kernels/src/split_mq4v2_z_betaalpha.hip`; model one-chunk gfx1100 smoke emitted `split_mq4v2_z_betaalpha` JIT code object and scored KLD `0.053701`.
